# EE311 Project: Chronic Kidney Disease (CKD) Classification

Scikit-learn models that predict whether a patient has chronic kidney disease,
using the UCI Chronic Kidney Disease dataset (400 patients, 24 attributes + class).

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate     macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Usage
Run the scripts from the project root folder:
```bash
python src/01_load_and_explore.py
```

## Project structure
```
data/     raw data (chronic_kidney_disease_full.arff)
src/      Python scripts (step by step)
images/   saved figures
```
